# 导入的候选（`harvest import` 的产物）

这里放的是从**别人发布的 TVBox 配置**里按名字筛出来的条目，用于人工复核。

- **pipeline 不读这个目录。** 它不在 `sites/registry.yaml` 里，`collect` / `generate` 都不会碰它。
- 每个文件带 `provenance`：来源 URL、抓取时间、匹配用的正则、原配置的站点/解析总数。
- 想把某一条变成真源，做法是把它写成 `sites/<key>.yaml` 配方，人工确认合规与可用性后再登记台账。

## 已知：名字里的「4K」多半不是 4K

首次导入（2026-10-17）的结果值得记一笔：

| 来源 | 站点 | 解析 | name 含 4K | 实际形态 |
|---|---|---|---|---|
| `13855863735/myTvBox18` | 101 | 22 | 1 | 1 条 parse（`4KTV` → `jx.4kdv.com`） |
| `wangguo0/tvbox-sub` | 1659 | 0 | 101 | **全部 type:3**，地址是 `csp_*`（网盘爬虫） |

也就是说：能搜到的「4K 线路」几乎都是**网盘/爬虫站**，需要对应客户端的 spider 才能播，不是可采集的 MacCMS 接口；
本项目的 T1/T3/T4 抓不到它们。而名字带 4K 的流实测也多为 1080p（见 README 的 SPS 一节）。

所以这里的条目是**线索**，不是可用的源。
